# Android Release Checklist

## Local MVP

- [x] Expo React Native source and Android JavaScript bundle built and reviewed
- [x] Bengali default and English language switch
- [x] Demo content clearly labelled; no real student data
- [x] Authentication unavailable message while no verified backend provider is configured
- [x] Course details do not invent price/schedule; saved course interest is not an admission application
- [ ] Accessibility labels, touch targets, keyboard and safe area reviewed
- [ ] Offline and error states checked
- [x] Android JS bundle, TypeScript and lint checks pass

## Release prerequisites

- [ ] JDK and Android SDK installed and versioned
- [ ] Approved application identifier, icon, splash screen and version
- [ ] Production backend, email/phone verification and RLS tested
- [ ] Privacy policy, data deletion, permissions and Play declarations reviewed
- [ ] No development credentials or demo data in release bundle
- [ ] Signed AAB built and tested on supported Android devices
- [ ] Release owner approval before any store submission

No Play Store submission or signing credential is authorized by this project task.
